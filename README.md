# AI-Powered Skin Disease Detection

### A Deep Learning Approach with ResNet50 and EfficientNetB0

This repository contains the implementation and resources for the research work **“AI-Powered Skin Disease Detection: A Deep Learning Approach with ResNet50 and EfficientNetB0”**, published in the **International IOT, Electronics and Mechatronics Conference (IEMTRONICS 2025)** and indexed by **Springer (Lecture Notes in Electrical Engineering, Volume 1468)**.

The project focuses on leveraging **deep learning and transfer learning** techniques to enable early, accurate, and accessible detection of common skin diseases using clinical images.

---

## 📌 Abstract

Skin diseases affect millions worldwide and early diagnosis is crucial for effective treatment. This work presents an AI-powered skin disease detection system using deep convolutional neural networks, specifically **ResNet50** and **EfficientNetB0**, to classify skin disease images with high accuracy.

The proposed system integrates:

* Transfer learning with pretrained CNN architectures
* Extensive image preprocessing and data augmentation
* A web-based application for real-time image-based diagnosis

The ResNet50 model achieved an accuracy of **83.61%**, demonstrating strong generalization capability. The system is designed to be **accessible, reliable, and efficient**, supporting early dermatological diagnosis and improved healthcare outcomes.

## 🧠 Models Used

* **ResNet50** – Residual learning with pretrained ImageNet weights
* **EfficientNetB0** – Parameter-efficient CNN with compound scaling
